# Bioinformatics Interactive Tutorials
## 生資互動式教學系列

> **A bilingual, browser-based bioinformatics curriculum — from foundation tools all the way to omics, AI, and research practice.**
> 一套雙語、瀏覽器即開即用的生資教學系列，從工具與基礎一路走到組學、AI 與研究實務。

This portal is the front door to **44 interactive learning modules**, organized into nine tracks (A–I) that build on one another. Every module ships with hands-on demonstrations, bilingual exposition (English / 繁體中文), and peer-reviewed references — designed for self-study, classroom use, and lab onboarding.

這個首頁是 **44 門互動式教學模組**的入口，依九大主題軸 (A–I) 分階段循序展開。每門課都附有可操作的示範、雙語講解 (English / 繁體中文) 與大量同儕審閱的文獻引用 — 適合自學、課堂教材或研究室訓練之用。

## 📚 What's inside · 課程地圖

The curriculum is structured as nine tracks that build on one another:

| | Track · 主題軸 | What you'll learn · 學什麼 |
|---|---|---|
| **A** | **Foundation Tools** · 基礎工具 | Version control, the Linux command line, Python and R working environments. 版本控制、Linux 命令列、Python + R 工作環境。 |
| **B** | **CS Foundations** · 資訊基礎 | Algorithms, data structures, computational thinking, and the data-science workflow. 演算法、資料結構、計算思維與資料科學工作流。 |
| **C** | **Bio Foundations** · 生物基礎 | Cells, molecules, genetics, biochemistry — the biology underlying every bioinformatics analysis. 細胞、分子、遺傳、生化 — 生資分析必備的生物核心。 |
| **D** | **Mathematics & Statistics** · 數學統計 | Linear algebra, probability, inference, and quantitative data analysis. 線性代數、機率統計、推論與定量資料分析。 |
| **E** | **Bioinformatics Core** · 生資綜論 | Sequence analysis, biological networks, biomedical informatics, simulation, and systems biology. 序列分析、生物網路、生醫資訊、模擬與系統生物學。 |
| **F** | **Omics Analysis** · 組學分析 | Bulk and single-cell RNA-seq, spatial transcriptomics, epigenomics, proteomics, multi-omics. Bulk / 單細胞 RNA-seq、空間轉錄體、表觀、蛋白與多組學整合。 |
| **G** | **Machine & Deep Learning** · 機器與深度學習 | Classical ML, deep learning, data mining — tailored for bioinformatics. 傳統機器學習、深度學習、資料探勘 — 為生資情境量身打造。 |
| **H** | **Advanced AI** · AI 進階 | Foundation models (Geneformer, scGPT), AI agents, biomedical big-data practice, AI literacy. 生物基礎模型、AI Agents、生醫大數據實務、AI 素養。 |
| **I** | **Research & Engineering** · 研究與工程 | Academic writing, advanced bioinformatics programming, bioimage analysis, biomedical engineering. 學術寫作、進階生資程式、生物影像分析、生醫工程。 |

## ⭐ Where to start · 從哪裡開始

The portal's **Featured Modules** section curates seven starting points covering different backgrounds:

入口頁的「**精選模組 (Featured Modules)**」區提供七個入門起點，覆蓋不同背景：

- **scRNA-seq** — the canonical pipeline (QC → PCA → UMAP → clustering → trajectory)
- **Biostatistics** — clinical-trial-grade statistical thinking
- **Spatial Transcriptomics** — Visium / Xenium / deconvolution
- **Git / GitHub** — version control essentials
- **R / tidyverse** — data wrangling and visualization in R
- **Linux for Bioinformatics** — Bash, SSH, SLURM, pipeline mindset
- **AI Agents** — tool use, ReAct, planning, multi-agent

### Suggested paths by background · 依背景的建議路徑

**If you come from wet-lab biology · 你是濕實驗背景：**
Start with **A** (tools), then **B** (CS), then **D** (math/stats). Bio is mostly review.
從 A (工具) 開始 → B (CS) → D (數學)；生物部分多半是復習。

**If you come from CS / data science · 你是 CS / 資料科學背景：**
Spend more time on **C** (bio) before diving into **E** (bioinfo core) and **F** (omics).
進入 E (生資綜論)、F (組學) 之前多花時間在 C (生物)。

**If you're new to both · 兩邊都是新手：**
Walk through A → B → C → D in order; the curriculum is designed for this.
依序學 A → B → C → D；課程就是為這個路徑設計的。

**Q: Why are some modules marked "In revision"?**
**Q: 為什麼有些模組標示「修訂中」？**

A "live" module is publicly stable; an "in revision" module has working content but is being refined. Both are safe to read — the difference is just whether wording / structure may still change.
「已上線」表示內容公開且穩定；「修訂中」表示有可用內容但仍在潤稿。兩者都可以放心閱讀，差別只在於用詞與結構可能還會微調。
